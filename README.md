# ألعاب بسيطة بالعربي 🎮

مجموعة ألعاب عربية قصيرة تشتغل من المتصفح مباشرة، بدون سيرفر ولا قاعدة بيانات. مبنية بـ HTML وCSS وJavaScript فقط، ومنشورة على GitHub Pages.

**العب الآن:** https://narjes455.github.io/mini-games/

## الألعاب

| اللعبة | الحالة | الوصف |
|---|---|---|
| خمّن الكلمة | ✅ متاحة | خمّن كلمة من ٥ حروف في ٦ محاولات، كل جولة كلمة جديدة، وتلميح يكشف فئة الكلمة |
| لعبة الذاكرة | ✅ متاحة | طابق أزواج الكروت، ٣ مستويات، لاعب أو لاعبين |
| خمّن شخصيتي | ✅ متاحة | ٢٤ شخصية مرسومة بالكود، ضد الكمبيوتر أو مع صديق من جهاز ثاني عبر WebRTC |
| إكس أو | ⏳ قريبًا | على نفس الجهاز أو من جهازين |

## المميزات

- واجهة عربية كاملة من اليمين لليسار، بهوية مستوحاة من نقوش السدو.
- تشتغل على الجوال والكمبيوتر.
- تطبيق ويب (PWA): تنضاف للشاشة الرئيسية وتشتغل بدون نت بعد أول زيارة.
- الإحصائيات والأرقام القياسية تنحفظ في متصفح اللاعب نفسه.

## هيكل المشروع

```
mini-games/
├── index.html          الصفحة الرئيسية (قائمة الألعاب)
├── manifest.json       إعدادات التطبيق (PWA)
├── sw.js               التشغيل بدون نت
├── icons/              أيقونات التطبيق
├── guess-word/
│   ├── index.html      لعبة خمّن الكلمة
│   └── words.js        الكلمات مقسّمة على فئات
├── memory/
│   └── index.html      لعبة الذاكرة
└── guess-who/
    └── index.html      لعبة خمّن شخصيتي
```

## كيف يشتغل اللعب مع صديق في خمّن شخصيتي

- اللاعب الأول يفتح غرفة برمز من ٤ أرقام، ويرسل الرابط أو رمز QR لصديقه.
- الجهازين يتصلون ببعض مباشرة عبر WebRTC باستخدام مكتبة [PeerJS](https://peerjs.com).
- كل جهاز يحتفظ بشخصيته السرية عنده، ويحسب جواب كل سؤال بنفسه، فما يقدر الخصم يشوف الشخصية من الكود.
- اللعب ضد الكمبيوتر يشتغل بدون نت.

## إضافة كلمات جديدة

افتح `guess-word/words.js` وأضف الكلمة داخل `words` في الفئة المناسبة. ولإضافة فئة جديدة انسخ أي فئة وغيّر `name` و`icon` و`words`. الشروط:
- الكلمة ٥ حروف بالضبط.
- الألف تنكتب بدون همزة (ا بدل أ إ آ).

## التشغيل على جهازك

```bash
git clone https://github.com/Narjes455/mini-games.git
cd mini-games
python -m http.server 8000
```
وافتح http://localhost:8000
